# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately via email to **[EMAIL_ADDRESS]**.

**Please include the following in your report:**

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

You will receive an acknowledgement of your report within 48 hours. If the issue is confirmed, we will work on a fix and release a patched version as soon as possible, typically within a few days.

## Reporting Issues

For non-security related bugs, feature requests, or general questions, please use the [GitHub Issues](https://github.com/WackyDawg/free-gpt-api/issues) page. 

Before opening a new issue, please search the existing issues to see if your problem has already been reported or discussed.
